## 📜 风险与合规声明

危信的核心功能——「读取微信界面」——在微信的用户协议文本里是被明文禁止的（《个人账号使用规范》1.2.6），没有「只读豁免」这回事。我们没有办法让它「完全合规」，只能守住红线、离平台真正会处罚的行为远一点，并把实情原原本本告诉你。

四条产品红线，代码库里不保留任何越线的路径：

| # | 红线 |
|---|---|
| 1 | **不接触微信进程**——不注入 DLL、不读写内存、不 hook 函数 |
| 2 | **不接触微信数据**——不读、不解密、不导出聊天记录与任何微信文件 |
| 3 | **不碰微信的事件**——不注入按键点击、不自动发送、不群发；只拦系统键盘的回车，「放行」也只是内部标记，由你自己再按一次回车 |
| 4 | **不上传任何内容**——纯本地、零网络，所有识别都在本机完成 |

一句话：**危信对微信只做两件事——看屏幕，以及拦住你自己的回车。**

平台实际处罚的是注入模块、群发行为和用户举报，危信一样都不沾，目前也没找到同类「只读工具」被封号的公开案例；但没找到不等于没有，平台保留随时认定的权利，**账号风险请自行斟酌**。协议原文摘录与逐条分析见 [docs/合规与风险说明.md](docs/合规与风险说明.md)（本人和AI一同的合规研究，不构成法律意见）。

## 🧭 这是什么

工作群里聊着正事，好友窗口里吐槽正酣——一个走神，把吐槽发进了公司群。撤回得再快，也快不过已经看到的人。

危信防的就是这一下。它常驻托盘，盯着你在目标聊天软件里敲下的字；按下回车的一瞬间，本地流水线（截图 → 区域划分 → OCR → 语义判定）完成分析，一旦发现这段话和当前的聊天对象、场景不匹配，就在消息发出去**之前**弹窗拦下你。

## ✨ 功能

| | 能力 | 说明 |
|---|------|------|
| 🛑 | **发送前拦截** | 拦下系统回车，判定通过才放行；弹窗可选「本次放行 / 直接发送草稿 / 回去继续改」 |
| ⚡ | **双速判定** | L1 规则引擎（违禁词、正则）毫秒级兜底；L2 语义模型（BGE 向量 + 联系人画像 + 场景规则）判断这话该不该在这儿说 |
| 👥 | **场景管理** | 给联系人画像、归场景：同一句话，发给闺蜜和发给老板，结果自然不同 |
| 🔤 | **违禁词库** | rules.toml 热重载，保存即生效 |
| 🏷️ | **区域模型自助训练** | 自带打标工具 UiTag，十几张截图就能训练适配自己界面的区域模型 |
| 🚀 | **GPU 加速** | ONNX Runtime + DirectML，N 卡 A 卡都能用；不发送时流水线挂起，不占资源 |
| 🔒 | **纯本地** | 零网络、零上传；弹窗之外不显示草稿，日志永不落原文 |

## 🚀 上手

1. 启动后驻留托盘。
2. 设置里**指定目标进程名**，开始监视；目标窗口没开时自动挂起。
3. 维护**联系人画像与场景**：哪些人算正式场合、哪些话不该对他们说。
4. 之后一切照旧。有风险，弹窗见；没风险，无事发生。

数据都在本机（`%APPDATA%\com.monostudio.dangerchat\`，设置里可查可迁）；卸载不会动它。

## 🧱 开发

Tauri 2 · Rust workspace · React 19 · zustand · Tailwind CSS 4 · TypeScript。

| 领域 | 选型 |
|------|------|
| 推理 | ONNX Runtime（ort，DirectML EP），全本地 GPU |
| OCR | rapidocr（det → cls → rec，PaddleOCR 系模型） |
| 区域划分 | YOLO 系轻量模型，用户可自助训练替换 |
| 语义 | BGE 向量 + 规则引擎（aho-corasick） |
| 并发 | std::thread + crossbeam-channel，刻意不用 tokio |

Rust 侧按 `dc-core`（配置/日志/模型）→ `dc-sys`（系统 API）→ `dc-pipeline`（intercept / capture / layout / ocr / sem / guard 流水线）→ `dc-bridge`（Tauri 通信）→ `src-tauri`（主程序壳）分层。完整设计文档见 [docs/](docs/)。

环境：Node ≥ 20、pnpm ≥ 11、Rust 1.98、Windows 10/11。

| 命令 | 用途 |
|------|------|
| `pnpm dev` / `pnpm dev:uitag` | 主程序 / 打标工具开发模式 |
| `pnpm build` | 发布构建 |
| `pnpm test` | 全量测试 |
| `pnpm test:fast` | 增量选测（日常用这个） |
| `pnpm test:golden` | 黄金集（需真实模型权重） |

> 架构细节、仓库约定与已知坑见 [CLAUDE.md](CLAUDE.md)。

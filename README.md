# 危信 DangerChat

Windows 桌面端「消息发送前风险确认助手」。当前处于 M0 技术尖峰阶段，**尚未交付可用产品**。

## 先回答风险

危信通过**截取显示器画面并在本机识别文字**来工作。

它**不会**：注入或修改微信程序、读取或解密微信聊天记录文件、替你发送任何消息、默认把内容上传到任何服务器。

它**只会**：阻止你自己的系统键盘发送键，然后提醒你；最终发送必须由你再按一次物理按键完成。

**协议风险**：微信《软件许可及服务协议》8.2.1.6 与《微信个人账号使用规范》1.2.6 禁止「通过非腾讯开发、授权的第三方软件……对微信软件及其组件、模块、界面、数据等进行访问、读取或控制」。**使用本类工具可能违反微信条款，存在账号被限制或封禁的风险，责任由使用者自行承担。** 详见 `docs/合规与风险说明.md`。

## 四条红线

1. 不接触目标程序进程：不注入 DLL、不读写内存、不 Hook 其函数。
2. 不接触目标程序数据：不读取、解密或导出聊天数据库及任何程序文件。
3. 不向目标程序发送任何输入：不调用 `SendInput`/`PostMessage`/`SendMessage`，不自动发送、群发或自动回复。
4. 不上传内容：默认零网络。

## 如何自行验证

- Wireshark 抓包：默认配置下不发起任何网络连接。
- Process Monitor / API Monitor：从不读取微信目录、访问其进程内存，也不投递输入或窗口消息。
- 源码完全公开，可自行审计与构建。
